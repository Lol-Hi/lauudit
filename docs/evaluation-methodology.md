# Evaluation methodology

The current MVP measures extraction and deterministic verification with adversarial examples: reversed names, fabricated citations, mismatched links, absent citations, ambiguous names, and claims with no matching paragraph. Rule support is a retrieval aid. The default heuristic is marked `SUPPORTED` only when overlap, rule context, and operative holding language all pass conservative thresholds; otherwise it is `UNCERTAIN` or `UNSUPPORTED`.

The optional `llm_judge` evaluator adds five contextual labels: `ENTAILED_RATIO`, `ENTAILED_OBITER`, `OVERGENERALIZED`, `CONTRADICTED`, and `UNSUPPORTED_NO_MATCH`. Its output is accepted only when the reasoning quotes a meaningful span from the retrieved paragraph. In live mode, the complete captured legal-AI response is provided as context while the judgment evidence is extracted ephemerally from verified eLitigation; citation placement is treated as variable rather than as a required bottom-of-answer format. No local-corpus fallback is used. Missing credentials, service failures, invalid JSON, unknown labels, or failed grounding produce an explicit unavailable result. The 100-row synthetic-demo fine-tuning set in `data/benchmarks/interpretation_gold.jsonl` is balanced across those labels, but it is not a substitute for a reviewed evaluation set based on real judgments.
